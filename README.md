# Sarcasm Detection

## Project Description
This project detects sarcasm and irony in social media and conversational text using Machine Learning.

## Features
- Detects sarcastic and non-sarcastic text
- Uses Machine Learning
- Uses the News Headlines Dataset

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- NLTK

## Dataset
News Headlines Dataset for Sarcasm Detection

## How to Run

1. Install the required libraries:
```
pip install -r requirements.txt
```

2. Run the project:
```
python main.py
```
